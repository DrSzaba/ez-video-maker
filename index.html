How to install

  1. Click Download for Windows above and save the zip file.
  2. Right-click the zip → Extract All, then double-click EZ-Video-Maker-Setup.exe.
  3. Click Next, Install, Finish. Start it from the Desktop shortcut.
Seeing a blue "Windows protected your PC" box? That's Windows being careful with any new program from a small maker. Click More info, then Run anyway. Everything the program needs is inside the setup — nothing else to download or install.

Questions

Does it need the internet?

No. Making, converting and saving all happen on your own computer. The only time you need internet is to download the setup.

Does it work on a Mac or phone?

Not yet — it's for Windows 10 and 11 (64-bit).

Is it really free? What's the catch?

No catch. No ads, no accounts, no watermark, no time limit. Donate only if you feel like it.

What format does it save?

MP4 (H.264), which TikTok, YouTube, Instagram, Facebook and DistroKid all accept. Choose vertical 1080×1920 for TikTok or horizontal 1920×1080 for YouTube.

Something went wrong — how do I get help?

The program keeps a note of any problem at %LOCALAPPDATA%\EZVideoMaker\crash.log. Send that text and describe what you were doing.
